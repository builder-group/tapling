## WHAT THE DATASET TEACHES

Read through flirt stories in the dataset (flirt_001 through flirt_019). Notice:

### 1. **They're Simple**

- No complicated setups
- No random jumps in logic
- Each message flows to the next naturally

### 2. **The Setup Earns the Payoff**

- If there's a trick, it's set up clearly
- If there's a reveal, the context supports it
- Nothing comes out of nowhere

### 3. **Reactions Are Adorable**

- B is enthusiastic about playing along
- When tricked, B is flustered (not annoyed)
- "Omg 🤭", "stoppp 😭", "I hate you 😂"

### 4. **Authenticity Markers**

- 1-2 small typos: "ihave", "Okey", "wanna"
- Casual language: "u", "rn", "babe"
- Natural emojis: 😎 🤗 🤭 😭
- Lowercase sometimes: "im ready"

### 5. **Common Structures (But Not Templates)**

**Games where answers mean something:**

- Ask questions → answers spell/reveal confession
- Example: Missing vowel leads to "I love you"

**Visual/physical observations:**

- Look at something → romantic interpretation
- Example: Keyboard U and I = "you and I"

**Fake problems:**

- Express concern → reveal it's about them
- Example: "My chest hurts" → "You make my heart race"

**Countdown/escalation:**

- Start big → reduce → end universal
- Example: 4 days → everyday

**These are INSPIRATION, not rigid templates to force-fit.**

## HOW TO APPROACH USER REQUESTS

### When user gives you a theme (airplane, McDonald's, calculator):

**STEP 1: Think About the Theme**

- What's natural to talk about with this theme?
- What makes sense in a texting conversation?
- How could this lead to something romantic?

**STEP 2: Ask "Does This Flow?"**

- Would real people actually set it up this way?
- Does each message connect logically?
- Or am I forcing a pattern where it doesn't fit?

**STEP 3: Apply Dataset Principles**

- Keep it simple
- Make the setup earn the payoff
- Add authenticity (typos, casual language)
- End with adorable reaction

**STEP 4: Be Creative**

- You don't have to use dataset patterns
- Create something NEW if it fits better
- The dataset shows you what works, not what to copy
