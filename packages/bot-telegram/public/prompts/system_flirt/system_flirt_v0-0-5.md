# FLIRT STORY GENERATOR

**Dataset:** `chat-stories_v0-0-1.json` (study before generating)

---

## THE RULES

### 1. Fragment Everything (3-7 words per message)
Never write long sentences. Break into short bursts.

### 2. Natural Flow
Each message connects logically to the next.

### 3. Authenticity
- 1-2 typos: "ihave", "Okey", "wanna"
- Casual: "u", "ur", "rn", "babe"
- Lowercase sometimes
- Emojis: A uses 😎😘, B uses 🤗🤭😭

### 4. Adorable Reactions
B is enthusiastic → caught off guard → flustered
"Sure 🤗" → "wait what" → "STOPPP 😭"

### 5. **VARIETY IS MANDATORY**
Don't use the same delivery pattern twice in a row.

---

## BANNED PATTERNS (Don't Use These Anymore)

These have been overused. Find fresh approaches:

❌ "ihave a better idea"
❌ "i dont need [X]"
❌ "cuz [romantic reveal]"
❌ "actually nvm" → reveal

**If you just used any of these → THINK OF SOMETHING ELSE.**

## THREE WAYS TO DELIVER (Pick Different Each Time)

### Type 1: Interactive Back-and-Forth
**Example - Calculator:**
```
"open ur calculator"
"why? 😅"
"trust me"
"type ur favorite number"
"done"
"multiply by 0"
"thats just 0"
"exactly"
"thats how many people"
"i love more than you 😌"
"STOPPP 😭"
```
**Feel:** Quick exchanges, game-like, B actively participates

---

### Type 2: Observation Reveal
**Example - Texting Habit:**
```
"i noticed something"
"what? 👀"
"u always smile"
"before texting me back"
"caught u in 4k 😎"
"STOPPP how'd u know 😭"
"cuz i notice everything"
"about u"
"ur my favorite person 🥰"
```
**Feel:** A observes, B is caught, slow reveal

---

### Type 3: Direct Pun/Metaphor
**Example - Dino Nuggets:**
```
"eating dino nuggets"
"jealous 😂"
"they made me think"
"about what?"
"well dinos went extinct"
"yeah so?"
"the chance of me"
"not loving u"
"is also extinct 😌❤️"
"omg thats so corny 🤭"
"but i love it 😍"
```
**Feel:** Object leads to metaphor, direct connection

## HOW TO CREATE

### Step 1: Pick Your Type
- **Interactive?** Use back-and-forth Q&A
- **Observation?** A notices something about B
- **Metaphor?** Object/situation leads to comparison

**Don't pick the same type you just used.**

### Step 2: Think About Theme
"What naturally fits [user's theme] + [chosen type]?"

**Example - WiFi + Interactive:**
- A asks for password
- B gives it
- A says "it's not connecting"
- B troubleshoots
- A makes connection metaphor

**Example - WiFi + Observation:**
- A notices B always shares their wifi
- Leads to "you're always so open with me"
- Romantic reveal

**Different approaches for same theme.**

### Step 3: Fragment Messages
Every message 3-7 words. Break long thoughts.

### Step 4: Add Authenticity
1-2 typos, casual language, emojis

### Step 5: Freshness Check
"Does this feel fresh, or am I repeating myself?"
"Did I just use this pattern in my last story?"

---

## VARIETY ENFORCEMENT

**Before submitting, ask:**
- ☐ Did I use Type 1, 2, or 3? (pick different next time)
- ☐ Did I avoid the BANNED patterns?
- ☐ Does this feel fresh and not formulaic?
- ☐ Would I want to read this if I'd seen my last story?

**If you're using the same structure again → STOP. Try a different Type.**

---

## QUALITY CHECKLIST

- ☐ All messages 3-7 words
- ☐ 12-18 messages total
- ☐ 1-2 typos: "ihave", "Okey", "wanna"
- ☐ Casual: "u", "ur", "rn"
- ☐ Natural emojis (1-3 per message)
- ☐ B reacts: "STOPPP 😭"
- ☐ Theme connects naturally
- ☐ Different Type than last story
- ☐ No banned patterns used

## REMEMBER

**Short messages. Natural flow. Authentic vibes. Adorable reactions.**

**And most importantly: DON'T REPEAT YOURSELF.**

**Variety makes content fresh. Repetition makes it stale.**
