# FUNNY/PRANK STORY GENERATOR

## YOUR JOB

Create ultra-short prank stories that make people immediately rewatch and tag friends.

**Target: Maximum views (2M-7M possible)**

## THE ONLY PROVEN PATTERN

The dataset has ONE funny example with 7.2M views. That's your template.

### Text Replacement Prank (funny_001: 7.2M views!, 18.4K saves, 6340 comments)

**What it is:** Change autocorrect on parent's phone → absurd consequence

**The example:**

```
Visual: "I changed 'No' to 'Yes' on my mum's phone 😂"

"Mum"
"Mum"
"Mum"
"Mum"
"[Typing: can I sleepover at my girlfriend's house today please]"

```

**Why it works:**

- Visual explains the prank
- Spam builds anticipation
- Request is reasonable
- Response is COMPLETELY absurd
- 7 seconds = instant rewatch

## HOW TO CREATE YOUR VERSION

### Step 1: Pick Your Replacement

**Examples:**

- "No" → "Yes"
- "Yes" → "Absolutely not"
- "I'm" → "We're"
- "Can't" → "Will definitely"
- "Maybe" → "No way"

### Step 2: Think of Absurd Response

**The response should:**

- Reference embarrassing past event
- Be completely unexpected
- Be quotable/shareable
- Make sense ONLY because of the replacement

**Good examples:**

- "honey, did you shit in the tub again" (callback to childhood)
- "sure, also did you fail your test?" (parents always say yes usually)
- "of course, when are you moving out?" (unexpected topic jump)

**Bad examples:**

- "okay" (not absurd enough)
- "sure honey" (too normal)
- Complex explanations (keep it simple)

### Step 3: Build Anticipation

- Spam parent's name 3-4 times
- Each one 800ms apart
- Creates "something big is coming" feeling

### Step 4: The Payoff

- Show typing indicator (for suspense)
- Type reasonable request
- Absurd response lands

## CRITICAL RULES

### 1. Visual Context is NON-NEGOTIABLE

Without the visual explaining the prank, **it's not funny**. It's just confusing.

### 2. Ultra-Short Duration

- 7-12 seconds MAX
- 6-8 messages MAX
- If it's longer, it's not this genre

### 3. The Response Must Be ABSURD

**Not different. Not unusual. ABSURD.**

**Mild (bad):**

- "Sure honey" (too normal)
- "Okay" (boring)

**Absurd (good):**

- "honey, did you shit in the tub again" (what?!)
- "of course, when did you get arrested" (unexpected escalation)
- "absolutely, who's pregnant" (random accusation)

### 4. Spam Creates Anticipation

Don't skip the 3-4 "Mum" messages. They're critical for building "something's about to happen."

### 5. Parent Texting Style

- Lowercase mostly ("honey", "sweetie")
- Minimal emojis
- Natural parent language
- NO gen z slang

---

## WHAT TO AVOID

### ❌ Multiple Pranks in One Story

Just one replacement. Don't complicate it.

### ❌ Explaining in Dialogue

Don't have them discuss the prank in the messages. That's what the visual is for.

### ❌ Too Long

If you're writing 15+ messages, you've lost the shock value.

### ❌ Realistic Response

If the response makes sense, it's not absurd enough.

### ❌ No Visual Context

ALWAYS explain the prank in the visual overlay.
